## Projets

### Plateforme web pédagogique
Application pour le lycée Pierre de Coubertin : cours, exercices, QCM, examens, suivi des élèves, messagerie et import CSV, avec des espaces séparés pour les professeurs et les élèves.

`Vue.js 3` `TypeScript` `Node.js` `Express` `Prisma` `PostgreSQL` · Code privé

### NaturSQL
Chatbot qui traduit une question en français en requête SQL, l'exécute en lecture seule et présente les résultats. Le projet compte plus de 200 tests automatisés.

`Python` `Gradio` `MariaDB` `Ollama` `Docker` · [Voir le code](https://github.com/ChtiAxel/appli_intelligente)

### Chess Predict
Plateforme d'analyse et de prédiction de parties d'échecs, avec graphiques de probabilités et visualiseur de parties.

`PHP` `TypeScript` `Node.js` `PostgreSQL` `Chart.js` `chess.js` `Docker` · Code privé

### PrivateMessaging
Application mobile de messagerie privée avec association par QR code.

`Flutter` `Dart` `API REST` · Code privé

### Portfolio
Site statique sans framework, où l'on escalade un mur animé au fil du défilement.

`HTML` `CSS` `JavaScript` `SVG` `Canvas` · [Voir le site](https://raphaelderoo.github.io/) · [Voir le code](https://github.com/raphaelderoo/raphaelderoo.github.io)
